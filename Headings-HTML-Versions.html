HTML Evolution

HTML 1.0

The beginning of HTML published in 1991. Limited functionalities.

HTML 2.0

Introduced new features such as tables which allows better organization of data.

HTML 3.0

Added new features to improve webpage design and formatting but was too complex, so most browsers only used parts of it.

HTML 3.2

Improved the features such as tables, forms, and text formatting.

HTML 4.0

Called COUGAR, added many new features from HTML 3.0 and became a standard in 1998, but it worked better in Explorer than in Netscape.

HTML 4.01

Improved media elements such as audio and video.

XHTML

Stands for eXtensible HyperText Markup Language. It was created to make web pages work better on new devices and browsers by enforcing cleaner, stricter coding rules.

HTML5

Is the latest version today. It improves HTML, supports new multimedia, reducing the need for plug-ins like Flash and working across all devices.
